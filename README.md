This repository contains a small project created for learning and practicing backend development with FastAPI. The main goal of the project is to understand how modern Python web APIs are built and structured.
To run the project locally:

1. Clone the repository
git clone https://github.com/BakdauletNN/practice_fastapi.git
2. Start the server
uvicorn app.main:app --reload
After starting the server the API will be available at:
http://127.0.0.1:8000
also provides automatic API documentation which can be opened in the browser:
http://127.0.0.1:8000/docs
